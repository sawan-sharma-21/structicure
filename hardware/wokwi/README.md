## ESP32 Hardware Simulation

StrucTiCure includes an ESP32-based circuit simulation developed using Wokwi.

**Simulation files:** [`hardware/wokwi/`](hardware/wokwi/)

- `diagram.json` — Circuit layout and component connections
- `sketch.ino` — ESP32 firmware
- `libraries.txt` — Required libraries

The simulation is intended to support development and testing of the project's hardware logic before physical deployment.

> Note: Simulation results do not replace validation on physical hardware.
